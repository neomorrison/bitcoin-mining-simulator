# Hash Forge

A bitcoin mining clicker. Strike the coin, build a mining empire from a garage CPU to a Dyson swarm, catch golden nonces and hard fork the chain for permanent keys.

**Play:** https://neomorrison.github.io/bitcoin-mining-simulator/

## How it plays

- **Strike** the coin (click, tap, Space or Enter). Every strike has a chance to find a **block** for a big payout. Fast strikes build a **combo** for extra power.
- **Rigs**: 11 tiers from Garage CPU to Dyson Swarm. Every rig doubles its output at 25, 50, 100, 150, 200, 300, 400 and 500 owned. Buy ×1, ×10, ×100 or Max.
- **Upgrades**: tiered upgrades for every rig plus strike, block, network, golden-nonce, combo and ability upgrades. "Buy all affordable" in one tap.
- **Golden nonces** drift onto the screen every minute or two: Lucky payouts, Frenzy (production ×7), Click Frenzy (strikes ×777), Block Rush and Coolant Flush.
- **Abilities** (keys 1 to 4): Overclock, Hash Storm, Nonce Magnet and Pool Hop, each on a cooldown.
- **Mods** cost stimulation, which you earn by playing. Each mod adds a bonus and a visual; turn any visual off and keep the bonus.
- **Hard fork** (prestige): reset rigs and upgrades for keys. Each key level adds +2% to everything forever, and keys buy **Genesis perks**.
- **Trophies**: 62 of them, each worth +1% to everything. The next closest one is always shown as your goal.
- Offline mining, autosave, save export and import, and settings for sound, screen shake, particles and number format.

Plain HTML, CSS and JavaScript. No build step: open `index.html` or serve the folder.
