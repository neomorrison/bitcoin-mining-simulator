# Hash Forge

An incremental Bitcoin mining simulator. Guess the nonce, forge a block, then scale the farm.

Open `index.html` or enable GitHub Pages on this repo.

## Play

1. Type `000000` in the manual hash terminal and forge.
2. Deploy hardware (CPU → GPU → FPGA → ASIC → farm).
3. Use powerups: overclock, liquid nitrogen, lucky nonce, merkle glitch.

Simulation only. No real cryptocurrency.
