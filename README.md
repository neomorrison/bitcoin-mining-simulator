# Hash Forge

An incremental Bitcoin mining simulator inspired by Cookie Clicker and Neal.fun’s Stimulation Clicker.

Open `index.html` or enable GitHub Pages.

## Play

1. Type `000000` and forge the first block.
2. Mash **Hash click** (or spacebar). Clicks mint **stimulation**.
3. Spend stimulation on chaos: bouncing ₿, rig quake, nonce rain, CRT, a hydraulic nonce press.
4. Catch market drops over the farm. They are not free.
5. Deploy hardware, research, then hard-fork for a permanent cut.

Simulation only. No real cryptocurrency.
